How to Build a Digital Planner Template for E-ink Devices

October 27, 2026 • 9 min read

Key takeaways

  • Set your canvas to your device's exact pixel dimensions, such as 1404×1872 for a reMarkable 2, so lines land where your stylus writes.
  • Export as vector PDF, never rasterized, and use Canva's PDF Standard option so internal hyperlinks survive the export.
  • Hyperlinked index pages and tab strips are the only fast navigation on e-ink, so test every link on the device after sideloading.
  • Design for greyscale contrast with 1 pt or heavier strokes, since hairlines vanish after e-ink dithering.
  • Build one source layout, then export a separately calibrated copy per device, because aspect ratios differ across panels.

You build a digital planner template by setting your canvas to your device's exact pixel dimensions (reMarkable 2 is 1404×1872, Supernote A5 X is 1404×1872, Kindle Scribe is 1860×2480), laying out your daily pages, adding hyperlinked navigation, and exporting as a vector PDF. This tutorial walks through the full build in Canva and Excel, then tests the same steps against a dedicated PDF designer.

What is a digital planner template and how does it differ from a printable planner?

A digital planner template is a PDF designed to be written on with a stylus on an e-ink device like a reMarkable, Supernote, BOOX, Kindle Scribe, or Kobo Elipsa. A printable planner is built for paper at 300 DPI and US Letter or A4; a digital template is built for one screen's exact pixel dimensions, so lines land where your nib does instead of a half-millimeter off. Three things separate the two. First, resolution: each device has a fixed panel size and PPI you calibrate to, which you can check on the manufacturer's spec pages such as reMarkable's product specifications. Second, navigation: a digital template uses hyperlinked PDF tabs and index pages, so tapping a date jumps straight to that spread. Third, file weight: e-ink handles vector PDF lines cleanly, so you draw rules and grids as vectors rather than embedding heavy images.

Get those three right and one template file works for years across your whole device.

How do you create a digital planner template in Canva step by step?

Setting the page size to your device's resolution

Start a custom-size design and enter your device's pixel dimensions directly: a reMarkable 2 is 1404 × 1872, so type those numbers into Canva's custom size field. Canva works in pixels, which maps cleanly onto PPI-based calibration. Divide dimensions by your PPI if you need inch-based spacing for margins.

Building the layout once and duplicating

Design a single daily page first: date block, three priority lines, hourly grid, notes area. Use Canva's ruler and guides to snap elements to consistent columns. When the page is right, duplicate it for every date in the planner, then edit only the date text on each copy. This keeps every page pixel-identical, which matters when a stylus writes across repeated layouts.

A practical Canva workflow for e-ink looks like this: build one master daily page with your grid, priorities, and notes areas locked to guides; duplicate it 365 times; batch-edit dates by selecting each text box in sequence; then add section pages (weekly, monthly, index) and link them later. The duplication step is where Canva earns its keep, because every copy inherits exact spacing, so your handwriting lands on the same coordinates on every page. Resist the urge to redesign mid-planner; a layout change after duplication means redoing every affected page by hand, since Canva has no true master-page inheritance for this kind of document.

Where Canva falls short for e-ink

Canva's PDF export flattens hyperlinks inconsistently, so navigation usually needs a second tool. There is no vector grid snapping calibrated to PPI, and 365 manual duplicates get slow. Ep Template Studio and Notebook Studio target this workflow directly; Canva is the free-form design layer, not the finish line.

How do you build a digital planner template in Excel with working tabs and formulas?

One sheet per planner page

Give each planner page its own worksheet and name tabs exactly as they should appear in the final PDF: "Cover", "Index", "January", "Daily". Set each sheet's print area to one page (Page Layout → Print Area) and set the paper size to match your device's aspect ratio, for example 1404 × 1872 px scaled to a custom page size. Keep the grid hidden (View → uncheck Gridlines) so only your drawn layout prints.

Date and weekday formulas

Drive every dated page from a single cell. Put the month start on each monthly sheet, then use =B1+1, =B1+2 across the week row, and =TEXT(B1,"dddd") for weekday names. Daily sheets can pull from a master index tab with =INDEX(Dates,MATCH(...)), so editing one cell re-dates the whole planner.

Exporting sheets to PDF

Use File → Export → Create PDF/XPS and choose "Entire workbook" so all tabs become one multi-page PDF; Microsoft documents the options on its Create PDF/XPS support page. Verify tab order matches page order before exporting, since Excel exports sheets left to right.

How do you add hyperlinked navigation between planner pages?

Hyperlinks are what turn a stack of pages into a planner. On an e-ink device you cannot swipe through a thumbnail sidebar the way you can in GoodNotes on an iPad, so a tappable index and tab bar are the only fast way to move between months, weeks, and daily pages. Every planner page should carry the same navigation strip so the link positions stay in muscle memory.

Link methods by tool

In Canva, select any element, press the link icon (or Ctrl/Cmd+K), and paste the page number of the target page in the same design. Canva only exports working internal links on PDF Standard, not PDF Print, so use PDF Standard for your planner file.

Excel cannot create page-to-page PDF links directly. The common workaround is to build the link layer afterward: import the Excel-exported PDF into a dedicated tool and draw link rectangles over your tabs. Canva and Figma fall into the same gap; their exports need a second pass. A dedicated PDF designer like Notebook Studio or Ep Template Studio lets you draw link rectangles directly on each page and point them at any other page, which is faster than post-processing.

Testing links on your device

Export, sideload the file, and tap every link before you call the planner done. Check the three failure modes: links that do nothing (wrong export setting), links offset from their tab graphic (element moved after linking), and links that jump to the wrong page (page numbers shifted when you duplicated or deleted pages). Fix them at the source file, re-export, and retest once.

Which page layouts should a daily digital planner template include?

A daily digital planner template needs four page types at minimum: an index, a day page, a week spread, and notes pages. Everything else is optional.

The day page

The day page carries the most decisions. Give it a fixed slot for the date, a schedule column with time rows at 30- or 60-minute intervals, and a task list with checkboxes sized for stylus taps. Keep the writing area at least 8 mm tall per line so handwriting on e-ink stays legible. Leave margins of 5 mm or more on every edge, since some devices crop close to the bezel.

Week and month spreads

The week spread is a seven-column or two-page layout with a small notes block per day. Build the month spread as a simple grid with clickable day cells that jump to the matching day page.

Notes and blank pages

Notes pages are just ruled, dotted, or blank canvases with a back-link in a corner. Add several duplicates; they get used more than you expect.

How do you calibrate a template to your e-ink screen?

Build the canvas at your device's native pixel dimensions, not a standard paper size. Commonly cited panels: reMarkable 2 at 1872×1404 (226 PPI), Supernote A5 X at 1404×1872, BOOX Note Air 2 at 1872×1404, Kindle Scribe at 3000×2000, and Kobo Elipsa at 1404×1872. Verify against your model's spec sheet, since BOOX ships many sizes.

Leave at least 8 mm of margin on the writing edge so palm rejection and toolbars don't cover content. Keep stroke widths at 1.5 pt or heavier; hairlines alias badly on 226 PPI panels. If your source layout lives in a spreadsheet, export it at full size rather than scaling down.

How do you make an aesthetic digital planner template that still works on tablets?

E-ink shows greyscale, so design for contrast, not colour. Use pure black text and lines on white, and reserve grey fills for headers or weekend rows, never for thin text on grey.

Line weight matters more than decoration: 1 pt minimum for rules and table borders, because 0.25 pt hairlines can vanish after e-ink dithering. Pick high-contrast fonts with clear letterforms (a slab or humanist sans) and avoid light weights below 12 pt equivalents.

Keep ink coverage low. Heavy dark backgrounds slow refresh on reMarkable, Supernote, and BOOX screens and look muddy after PDF conversion. Test one page on your actual device before building the full hyperlinked planner, and check it in greyscale preview before exporting vector PDF.

How do you export and share your digital planner template for GoodNotes, Notability, or print?

Vector vs rasterized export

Always export as vector PDF. Vector lines stay crisp at any zoom level and keep file sizes small, which matters on e-ink devices where every page redraw costs battery and lag. In Canva, choose File type: PDF Standard, never PDF Print with rasterization. In Excel, print to PDF with "Fit to page" disabled so your calibrated dimensions survive.

Keep hyperlinks intact by flattening nothing: Canva's PDF Standard export preserves links, and Excel's Save As PDF keeps internal tab links if you built them with HYPERLINK functions. GoodNotes documents supported import formats and hyperlink behaviour in its help centre, so verify against your target app before shipping.

Name files with device and resolution, e.g. supernote-aurus-daily-1404x1872.pdf.

Sharing and selling your template

For buyers, ship the finished PDF plus a short setup note listing target device and PPI. For print, export a separate copy at 300 DPI equivalent and check margins. If you sell on Etsy, a single calibrated file per device converts better than one multi-device bundle, because reviews punish mismatched aspect ratios.

Which tool should you use: Canva, Excel, or a dedicated PDF designer?

Match the tool to the bottleneck. Canva is fastest for visual layouts but gives you little control over exact PPI calibration on a reMarkable or Supernote. Excel handles formulas and date logic well, yet produces clunky visuals and needs a PDF printer driver for vector output. Figma and ToonSquid offer precision drawing but expect you to assemble hyperlinks and page order by hand.

Ep Template Studio automates e-ink-specific sizing. Notebook Studio does the same for hyperlinked, vector PDF export, but it only designs PDFs: if you want formulas, you still build them in Excel and import. If you build one planner a year, Canva is fine; if you calibrate per device and iterate weekly, a dedicated designer pays for itself.

FAQ

Is there a free digital planner template I can download to reverse-engineer?

Yes. Template makers on Etsy and Gumroad often list free samples, and device communities share user-built PDFs. Open one in a PDF viewer to inspect its link structure and page dimensions, then rebuild the layout in your own tool. Reverse-engineering a working file is the fastest way to see how index pages and tab bars fit together.

Can I use one digital planner template across reMarkable, Supernote, and Kindle Scribe?

Not well. Each panel has different pixel dimensions, so a file calibrated for 1404×1872 will letterbox or stretch on the Scribe's 1860×2480 screen. Mismatched aspect ratios also shift where your stylus lands relative to printed lines. Build one source layout, then export a calibrated copy per device and name files with the resolution.

Do hyperlinks in a PDF planner actually work on e-ink devices?

Yes, on most current devices. ReMarkable, Supernote, BOOX, and Kindle Scribe all support tappable internal PDF links, which is why index pages and tab strips matter. The failure point is usually the export: flattened or rasterized PDFs lose links. Test every link on the device itself after sideloading, and fix problems in the source file.

What size should I design a digital planner template for GoodNotes?

GoodNotes imports PDFs at any size and scales them to the canvas, so design at the pixel dimensions of the device you write on, such as 1404×1872 for an A5-class panel. Keep the aspect ratio consistent with your screen so imported pages fill it without margins. Check GoodNotes' help centre for current import behaviour before shipping.
