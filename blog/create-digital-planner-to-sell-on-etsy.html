How to Create a Digital Planner to Sell on Etsy

October 30, 2026 • 10 min read

Key takeaways

  • Design planner pages at your target device's exact native resolution, since iPad buyers want 4:3 landscape while e-ink devices like the reMarkable 2 need 3:4 portrait at 1404 x 1872.
  • Build two-way hyperlink navigation with a tab strip in the same position on every page and a return-to-index link on each inner page, because link architecture is the product.
  • Export from Canva using PDF Standard, not PDF Print, since PDF Standard preserves hyperlinks and produces smaller files that turn pages faster on e-ink screens.
  • Undated planners sell year-round and avoid the annual rebuild that dated planners require every January, though dated listings rank harder on seasonal searches.
  • Free Canva elements can be used commercially in a flattened PDF sold on Etsy, but you cannot resell the Canva template itself or leave pages unflattened.

To create a digital planner to sell on Etsy, design a hyperlinked PDF in Canva at your device's exact resolution, build an index-tab navigation system, export as a PDF with links preserved, then list it as an instant download. This guide covers the hyperlink-architecture decisions most tutorials skip, calibrated for iPad and e-ink buyers.

What does it take to create a digital planner to sell on Etsy?

Five steps: design pages at the right size for your buyers' devices, plan the hyperlink architecture, build the template, export a PDF that keeps every link intact, then list it on Etsy. Each step has a decision that most first-time sellers get wrong, and the rest of this guide walks through them in order.

The two buyer platforms that change your design decisions

iPad buyers in apps like GoodNotes expect landscape pages, color, and heavy visual styling. E-ink buyers on reMarkable, Supernote, BOOX, and Kindle Scribe expect portrait pages matched to their device's exact resolution, dot grids that survive screen calibration, and fast page turning with minimal ink refresh. One template rarely serves both well; decide your primary platform before you draw anything.

If you design with free Canva elements, check the Canva content licence terms before listing, since commercial use rules differ between free and paid elements. For tool-specific walkthroughs and export notes, we keep ongoing notes at https://notebook-studio.com/blog.

What size and resolution should Canva pages be for an iPad and e-ink planner PDF?

Why e-ink buyers check calibration before buying

E-ink shows every misalignment. A template exported at the wrong PPI produces handwriting that sits slightly off the dot grid or hyperlinked tabs that drift from the page edge. Export at the device's native resolution or exact 2x, so one screen pixel maps to one template pixel. The habit tracker and dot grid spacing advice in our e-ink layout guide applies here: design at 1:1 for your target device, then duplicate the file per device family. Notebook Studio ships templates at each device's native hardware resolution for this reason, though Canva can get close by setting custom pixel dimensions per export.

What sections and pages does a sellable digital planner template need?

A sellable planner needs a cover, an index page, and yearly, monthly, weekly, and daily spreads. That is the minimum set Etsy buyers expect at any price. Anything less reads as a worksheet, and reviews will say so.

Minimum page set vs premium page set

The minimum set works as an undated starter planner. A premium set adds a dated yearly calendar, monthly notes pages, project or habit trackers, and a linked section divider for each module. Keep every page on the same canvas size from the start, because Canva's PDF export carries your links through but won't fix mismatched page dimensions later (Canva Help Center on PDF export). For e-ink devices like the reMarkable, build at the device's native resolution so the dot grid lines up with the pen's calibration.

Section pages that justify a higher price

Buyers pay more for navigation: a tabbed index that jumps to each month, and section pages that jump back. Build those links on dedicated divider pages rather than burying targets inside spreads. Tools like Notebook Studio's reMarkable planner designer exist because hand-placing hundreds of link rectangles in a general design tool gets tedious fast; the honest tradeoff is that Canva gives you more decorative elements, while purpose-built editors give you faster link management.

How do you plan hyperlink architecture before you design?

Index tabs: how many and where

Put a tab strip on every page, same position, same tap targets. Five to eight tabs covers most planners: index, monthly, weekly, daily, notes, templates. More tabs means smaller tap targets, which fails on e-ink where a mis-tap costs a page turn.

One-way vs return links

Every link you add should have a way back. A daily page that links forward to its week but has no return forces users to swipe through the whole document. Two-way linking is what separates a sellable planner from a PDF of worksheets.

Mapping link structure to buyer expectations

Here is the decision most tutorials skip, stated plainly: your link architecture is the product. Etsy buyers judge a hyperlinked planner within seconds of opening it, and on e-ink devices like a Supernote or reMarkable there is no thumbnail sidebar to bail them out, so the tab strip is the only navigation they have. That means tabs must sit in the same spot on every page, sized for a stylus tap, with an index page linking to every section and every section landing on a page that links back to the index. Dated planners need per-day links built from a repeating master spread; undated planners can lean on month and week landing pages instead, which is one reason undated files are faster to build.

If a buyer on a BOOX Note Air 3C taps a tab and lands somewhere unexpected, that is a review, not a preference. Tools like hyperpaper and Ep Template Studio sell on this structure, and Notebook Studio (https://notebook-studio.com/support.html) treats link placement as a first-class step rather than an afterthought. Sketch the whole map on paper before you open any editor; retrofitting links is the slow way.

How do you add and test hyperlinks in a Canva digital planner template?

Setting links in Canva step by step

Draw a rectangle or insert a shape over each index tab, then set its transparency to 1% so it stays invisible on the page. With the shape selected, open the link tool, choose "Page", and pick the target page number. Repeat for every tab, then add a "Go to page 1" shape on every inner page so buyers can always jump back to the index. On e-ink devices like the Kindle Scribe, tap targets need to be generous; a designer building for that screen can check placements against native dimensions in a dedicated tool like Notebook Studio.

The testing pass that catches broken navigation

Export the PDF, open it in a reader, and click every single link, in order, from page one. Confirm each tab lands on the right section and every back-to-index shape works. Then test on a second device or app, since tap behaviour differs between iPad and e-ink readers. Fix any dead link before listing, because a buyer who hits one broken tab within a minute will ask for a refund.

How do you export a Canva planner so hyperlinks survive the PDF?

Which export setting keeps links clickable

Use PDF Standard, not PDF Print. Canva's PDF Standard export preserves embedded hyperlinks; PDF Print flattens the file for press-quality output and drops them, which kills every index tab and section link you built. Download, open the result in a PDF viewer, and tap each tab before you list anything on Etsy. A broken link in the sample a buyer tests is the fastest route to a return request.

File size limits on e-ink devices

PDF Standard also produces smaller files, which matters on a reMarkable or Supernote where a 200-page planner can bloat past 100 MB with PDF Print and slow page turning. Compress images before export and delete unused pages. Etsy's Seller Handbook recommends keeping digital listings fast and easy to download, and a lean PDF is part of that first impression.

Own-tool note: Notebook Studio exports vector PDFs at native device resolutions with links intact, but it skips Canva's element library, so if your template lives in Canva, PDF Standard is the honest answer.

Should you sell a dated or undated digital planner on Etsy?

The maintenance cost of dated planners

A dated planner ranks hard on seasonal searches every January, but it dies on December 31. You re-export every page, re-verify every hyperlink, and relist each year, or your listing becomes dead inventory. If you sell dated, build the calendar layer last so the hyperlink architecture survives the annual swap.

Why undated wins for e-ink buyers

reMarkable, Supernote, and BOOX owners treat a digital planner like a notebook they refill, not a product they replace. Undated templates sidestep the yearly rebuild and sell year-round, which matters more when your buyers calibrate PPI and page turning rather than chasing a calendar year. The tradeoff: undated listings face steadier competition and weaker January spikes. A middle path is an undated core with an optional dated add-on listing you refresh annually.

Can you use free Canva elements in a planner you sell commercially?

Yes. Canva's content licence agreement lets you use free elements and Pro elements in a planner PDF you sell on Etsy, as long as you export it as a flattened PDF where the graphics can't be extracted and resold as-is. What's prohibited: listing a Canva template itself for sale, or selling unflattened pages where buyers can copy the artwork.

Two practical traps for e-ink sellers: skip photos with faces, since device screens render them poorly and buyers on r/RemarkableTablet expect line art, dot grids, and vector-style shapes. And never use Canva's fonts as your "handwriting" promise if you deliver a typed planner; on a reMarkable or Supernote, buyers expect their own pen strokes to fill the pages.

How do you price and list a digital planner on Etsy as a first-time seller?

Pricing your first listing

First-time planner sellers on Etsy typically land between $5 and $25, with undated hyperlinked planners at the lower end and dated, device-specific ones higher. Start around $8–12, then raise price once you have reviews. Digital listings carry no reprint cost, so the only real expense is your time.

Listing elements that convert

Your first three photos do most of the selling: show the index page, a hyperlinked section spread, and the planner running on a reMarkable or BOOX screen, not just an iPad. State exact page dimensions in PPI-friendly terms (e.g. reMarkable 2 native resolution), confirm hyperlinks work in the delivered PDF, and name which devices you tested on. Deliver a single PDF as an instant download; buyers on e-ink want offline files, not links to external viewers.

Where Canva fits against dedicated planner tools

Canva is the fastest path to a first listing, and it is free to start. But it designs at generic canvas sizes, so you calibrate manually for each device. Notebook Studio, Ep Template Studio, and hyperpaper build templates at native hardware resolutions from the start, which saves the calibration pass. Honest tradeoff: Canva's element library beats the dedicated tools for decoration, while they win on exact e-ink dimensions. Pick based on whether your first listing targets iPad buyers (Canva is fine) or reMarkable and Supernote owners (dedicated tools pay off sooner).

FAQ

Do I need Canva Pro to create a digital planner to sell on Etsy?

No. Canva's licence lets you sell planners built with free elements, provided you export a flattened PDF where the graphics can't be extracted. Pro elements are also permitted, but they mostly add decoration, and e-ink buyers prefer vector-style line art and dot grids anyway. Start free and upgrade only if a specific element justifies it.

How many pages should a hyperlinked digital planner have for reMarkable or Supernote?

A sellable minimum is a cover, an index, and yearly, monthly, weekly, and daily spreads, plus a linked divider for each section, which lands around 15 to 25 pages undated. Dated versions run longer. Keep the file lean regardless, since oversized PDFs slow page turning on e-ink screens.

Can I sell the same planner PDF for both iPad and e-ink devices?

You can, but one template rarely serves both well. iPad apps like GoodNotes expect landscape, color-heavy pages, while reMarkable and Supernote need portrait files at each device's exact native resolution. The safer route is a primary platform per listing, or separate iPad and e-ink versions sharing the same underlying design.

How do I deliver the planner files to Etsy buyers after purchase?

List it as a digital instant download and deliver a single flattened PDF with all hyperlinks intact. E-ink buyers want an offline file they can import straight into their device's app, not a link to an external viewer. Confirm every link works in the exported file before you publish the listing.

What keywords should I use in my Etsy listing for a digital planner?

Target device-specific phrases buyers actually type: "digital planner reMarkable 2", "Supernote planner", "Kindle Scribe planner", or "GoodNotes planner" depending on your platform. Add "hyperlinked", "undated" or the calendar year, and state the native resolution in the description. Device-specific, dated listings also support higher prices than generic undated ones.
